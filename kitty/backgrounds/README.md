Coloca aquí tus JPG, PNG o WEBP. Los dos JPG originales se conservan como archivos,
pero no se seleccionan como fondo por defecto. Edita `../background.conf`, por ejemplo:

    background_image backgrounds/mi-fondo.jpg

También puedes usar `background_image backgrounds/*.jpg` para rotarlos con
Ctrl+Shift+F11/F12. Kitty 0.49.1 resuelve las rutas desde su configuración.
